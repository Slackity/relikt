# RELIKT — магазин в Telegram и на сайте

Один и тот же сайт работает и как мини-апп в Telegram, и как обычный сайт:
**https://slackity.github.io/relikt/**

- каталог с фильтрами, поиском и избранным, страница товара с галереей;
- корзина с промокодами и скидками, оформление: контакты, ПВЗ, полная оплата или бронь;
- шаг оплаты с реквизитами и чеком. Заказ с чеком уходит менеджеру в Telegram через Cloudflare Worker;
- админка `admin.html`: товары, фото, категории, все тексты сайта на русском и английском, настройки, импорт из канала.

Хостинг бесплатный: GitHub Pages. Отдельного сервера нет.

## Как это устроено

| Что | Где |
| --- | --- |
| Товары, категории, тексты, настройки | `data/store.json` |
| Фото товаров | `uploads/` |
| Страницы | `index.html`, `catalog.html`, `product.html`, `admin.html` |
| Скрипты и стили | `js/`, `css/` |
| Импорт из канала | `tools/import-channel.js`, запускается кнопкой в админке через `.github/workflows/import.yml` |
| Номер сборки | `version.json` и `tools/bump-version.js` |
| Worker для заказов (Cloudflare) | `worker/index.js` |

Админка ничего не хранит у себя: каждое сохранение — это коммит в этот репозиторий.
GitHub Pages пересобирает сайт за 1–2 минуты, и изменения появляются у всех покупателей.

## Админка

Открыть админку можно двумя способами:
- в мини-аппе: у владельца в меню и внизу страницы есть ссылка «Админка». Кто её видит, задаётся в «Настройки → Доступ»;
- в браузере: `https://slackity.github.io/relikt/admin.html`.

Для входа нужен GitHub-токен. Если вы уже входили в старую админку на этом телефоне, токен подхватится сам.

Как создать токен:
1. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new token.
2. Repository access: *Only select repositories* → `relikt`.
3. Permissions: **Contents — Read and write** и **Actions — Read and write**. Второе нужно для импорта из канала.
4. Вставьте токен в админку. Он хранится только на этом устройстве, никому его не пересылайте.

Чужой человек без токена ничего изменить не может, даже если откроет `admin.html`.

### Импорт из Telegram
«Товары → Импорт из Telegram» запускает задачу на GitHub. Она читает публичную ленту `t.me/s/relikt_store` и делает следующее:
- добавляет новые товары: название, бренд, цену (эмодзи-цифры, 🕖 = 0), размеры, «под заказ» и до 6 фото;
- помечает проданными вещи, у которых в посте появилось «Продано»;
- пропускает посты, товары из которых вы удалили в админке.

По умолчанию новые товары сохраняются черновиками. Проверьте их и опубликуйте.
Импорт можно запустить и вручную: вкладка **Actions → Import from Telegram → Run workflow**.

**Автоимпорт** («Настройки → Telegram → Автоимпорт новых постов с вещами»): Worker видит новый пост в канале с фото и ценой и сам запускает этот импорт — вещь появится в каталоге через 2–3 минуты (черновиком или сразу, как выбрано). Если в пост дописать «Продано», импорт тоже запустится и отметит вещь проданной. Нужно: Worker от 14.10.2026, у `GITHUB_TOKEN` в Worker — право **Actions: Read and write** (кроме Contents), после обновления Worker нажать «Подключить бота». Если запустить не получится, менеджеру придёт предупреждение.

## Заказы

Покупатель проходит четыре шага:
1. Корзина: промокод и скидки-галочки.
2. Данные: имя, Telegram, телефон, город, доставка, адрес ПВЗ, полная оплата или бронь.
3. Оплата: реквизиты из настроек, банк, с которого перевёл, и чек.
4. Заказ и чек уходят через Worker (`Настройки → Приём заказов`) в чат менеджера.

В мини-аппе запрос подписывает сам Telegram, Worker проверяет подпись (`initData`).
С обычного сайта заказ принимается по «секрету заказа» (`APP_SECRET`). Если секрет пустой, покупатель получает готовый текст заказа и отправляет его менеджеру сам. Такие заказы не попадают во вкладку «Заказы» и не отмечают вещи.

На шаге «К оплате» Worker закрепляет вещи за покупателем на 20 минут: он видит обратный отсчёт и спокойно переводит деньги, а другие в это время видят «Оформляется» и к оплате этой вещи не попадут. Не отправил заказ за 20 минут — вещь освобождается сама. Так двое не заплатят за одну вещь.

После заказа Worker делает три вещи:
- проверяет, что вещи ещё можно купить. Если вещь уже продана или в брони, покупатель видит «уже недоступна», а менеджеру ничего не приходит;
- отмечает вещи в каталоге: полная оплата убирает единицу из наличия, последняя единица становится «Продано»; при брони вещь получает статус «Бронь» на срок из настроек. На сайте это видно через 1–2 минуты;
- сохраняет заказ для вкладки «Заказы» в админке. Заказы хранятся в Cloudflare (не в этом открытом репозитории) один год.

Если покупатель всё же отправил чек за вещь, которая уже ушла (например, не уложился в 20 минут), заказ не теряется: он приходит менеджеру с пометкой «⚠️ ВЕЩЬ УЖЕ НЕДОСТУПНА: покупатель оплатил, нужен возврат или замена» и попадает во вкладку «Заказы» со статусом «Возврат/замена».

Во вкладке «Заказы» статус «Оплачен» превращает бронь в продажу, а «Отменён» возвращает вещи в продажу.

Проверить связь с Worker: «Настройки → Приём заказов → Проверить Worker».

## Worker (Cloudflare)

Код лежит в `worker/index.js`. Он умеет всё то же, что и прежний Worker (заказ и чек в Telegram, СДЭК, Яндекс Доставка), плюс хранит заказы и меняет наличие в каталоге.

Как обновить:
1. Cloudflare → **Workers & Pages** → `relikt-orders` → **Edit code**. Замените весь код содержимым `worker/index.js` и нажмите **Deploy**.
2. **Storage & Databases → KV → Create** — создайте хранилище, например `relikt-orders`.
3. Worker → **Settings → Bindings → Add → KV namespace**: Variable name **`ORDERS`**, хранилище из шага 2.
4. Worker → **Settings → Variables and Secrets → Add → Secret**: имя **`GITHUB_TOKEN`**, значение — fine-grained GitHub-токен с правом **Contents: Read and write** на репозиторий `relikt`. Можно тот же, что и для админки.
5. В админке: «Настройки → Приём заказов → Проверить Worker». Должно быть «Telegram, заказы и наличие в каталоге настроены».

6. В админке: «Настройки → Приём заказов → Подключить бота». После этого бот отвечает на /start приветствием и кнопкой «Открыть каталог» (а по ссылке на вещь — ещё и «Открыть вещь»), появляются команды /start и /catalog, а если у бота не было кнопки меню — кнопка «Каталог».

Кнопка под постами с вещами — включается галочкой «Настройки → Telegram → Сообщение с кнопкой…», по умолчанию выключена (бот — админ канала с правом публиковать сообщения, после обновления Worker нажать «Подключить бота»): Telegram не разрешает кнопки под альбомами, поэтому сразу после нового поста с фото и ценой бот тихо отправляет в канал короткое сообщение «Название · цена» с кнопкой «Открыть в каталоге». Кнопка открывает мини-апп на этой вещи (когда она уже импортирована), до импорта — каталог. Посты без цены, с «Продано» и репосты бот не трогает; импорт эти сообщения пропускает.

Свой пост с кнопкой (анонс, акция): Telegram не даёт ставить инлайн-кнопки из приложения, их ставит бот. Пришлите боту в личку текст или одно фото / GIF / видео с подписью. Бот покажет пост ровно так, как он будет выглядеть в канале, с кнопкой «Открыть каталог» (она открывает мини-апп), и спросит: «Опубликовать», «Без звука» или «Отмена». Свои кнопки пишутся последними строками поста:

```
Кнопка: Открыть магазин
Кнопка: Отзывы - https://t.me/relikt_feedback
```

Первая открывает мини-апп, вторая ведёт по ссылке; эти строки в канал не попадут. Публиковать так могут только Telegram ID из «Настройки → Доступ». Под альбомом кнопки невозможны. После обновления Worker нажмите «Подключить бота».

7. Пост с каталогом в канале: «Настройки → Приём заказов → Закрепить пост с каталогом». Бот (админ канала с правами публиковать и закреплять) опубликует пост «RELIKT — каталог» с кнопкой «Открыть каталог» и тихо закрепит его. В канале кнопка не может открыть мини-апп напрямую, поэтому это ссылка `t.me/<бот>?startapp` — она открывает мини-апп.

Если токен в Worker истечёт, заказы продолжат приходить, но вещи перестанут отмечаться: менеджеру придёт предупреждение. Тогда обновите `GITHUB_TOKEN`.

## Ссылки на товары через Telegram

В «Настройки → Telegram → Ссылка на мини-апп» укажите адрес мини-аппа, например `https://t.me/имя_бота` или `https://t.me/имя_бота/app`.
Тогда «Скопировать ссылку», «Спросить в Telegram» и ссылки в заказах ведут на `t.me/…?startapp=p_<товар>`: такая ссылка открывает этот товар прямо в мини-аппе.
Для варианта `t.me/имя_бота` у бота должен быть включён основной мини-апп: @BotFather → бот → Bot Settings → Configure Mini App.

## Обновление кода

Telegram сильно кеширует страницу мини-аппа. После изменения файлов в `js/` или `css/` поднимите номер сборки:

```
node tools/bump-version.js
```

Открытые копии сами увидят новый `version.json` и перезагрузятся. Товары, тексты и настройки из админки этого не требуют.

Посмотреть сайт у себя на компьютере (нужен Node.js 18+):

```
node tools/serve.js
```

Сайт откроется на http://localhost:3000. Админка и там сохраняет прямо в GitHub.
